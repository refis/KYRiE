## 1. 実行形式（確定方針）

**PyInstaller／Nuitka 等による EXE 化、および EXE の配布・試験ビルドは実施しない。**
Npcap・管理者権限・表示JSON編集・辞書更新はソース起動のまま扱う。
ソーススナップショットは EXE 配布や公開リリースではない（[releases/README](../releases/README.md)）。

## 3. GUI ユーザビリティ

### 結論

次は **発見性** と **診断への導線**。利用感が変わるため、**v0.0.10 スナップショット保存後**に着手する。
簡易モードや大規模レイアウト改修は後段。

### 段階（P2）

- **P2-1（済）**: ヘルプ／About、主要 toolTip、状態ラベルクリックで診断
- **P2-2（済）**: F5／F8／Ctrl+Shift+O、開始前チェックリスト（設定は黙って変えない）
- **P2-3（済）**: 観測中心／復元中心のタブ初期プリセット（下記）

対象外: 未観測条件の自動補完、取得契約の緩和、推測による命令増加、EXE化。

### P2-3 詳細（タブ初期プリセット）

主画面のワークスペースは用途別タブが並ぶ（観測ログ・パケット詳細・NPC・MOB・会話・コード・演出比較など）。
復元作業では会話／演出を多用し、ライブ観測では観測ログ／パケット詳細を多用する一方、
毎回同じタブを手で選ぶ手間と「どこから見ればよいか」の迷いがある。

**実装:**

| 項目 | 内容 |
|------|------|
| プリセット名 | 「観測中心」「復元中心」 |
| 観測中心 | 起動時または選択時に「観測ログ」を前面 |
| 復元中心 | 「会話・コード」を前面。NPC／MOB／演出比較タブは残す |
| 保存先 | `config/user_settings.json` の `workspace_preset`（`observe`／`restore`）。ローカル専用 |
| 切替 UI | 設定→表示のコンボ、および作業→タブ初期表示。タブ削除・統合はしない |
| やらないこと | パネル非表示、生成規則の変更、未選択タブの破棄 |

**境界:**

- プリセットは「最初に開くタブ／フォーカス」だけを変える。全タブは残す。
- 利用者の明示選択または保存済みプリセットのみ適用。Git／スナップショットで上書きしない。
- 作業プロジェクトの保存済み `view.tab` は開いたときに優先する（プリセットを上書きしない）。
- 簡易モードとして解析や根拠表示を削らない（証拠契約を弱めない）。

## 4. ローカル設定の扱い（ignorepacket / user_settings）

| ファイル | Git | スナップショットZIP | 不在時 |
|----------|-----|---------------------|--------|
| `config/user_settings.json` | 対象外 | 入れない | メモリ上 DEFAULTS。保存時に生成 |
| `config/ignorepacket.json` | 対象外 | 入れない | `ensure_default_file` で空プリセット生成（既存は非上書き） |
| `config/ignorepacket.example.json` | 追跡 | 含めてよい | 雛形のみ |

**背景:** 以前は空の `ignorepacket.json` をリポジトリと ZIP に載せていたため、
`git pull` やスナップショット展開でローカル除外リストが空データに潰れる恐れがあった。
Python 側の既定生成＋Git/ZIP除外で、更新取り込み時の破壊を避ける。

## 推奨の着手順

1. **v0.0.10 ソーススナップショット**で現状の利用感を保存する（済）。
2. 操作ガイド純化と GUI P2-1／P2-2（済）。
3. ローカル設定の不在時生成と Git/ZIP 除外（本節）。
4. P2-3 タブ初期プリセット（済）。物理 docs 大移動は明示指示の後。

## 非目標

- EXE化・EXE配布・公開ストア配布。
- Linux CI offscreen 成功を Windows／Npcap 実機の代替にしない。
- 「全MARiA互換」を完了条件にしない。

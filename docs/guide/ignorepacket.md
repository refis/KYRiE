# 観測ログの非表示設定

[資料一覧へ](../README.md) · [プロジェクトREADME](../../README.md)

「観測ログ」上部の「非表示設定（ignorepacket）…」で設定し、保存すると既存の表示にも適用する。
「MOBのスキル・攻撃を非表示」は上部のチェックでも切り替えられる。
設定はローカル専用の `config/ignorepacket.json` へ保存し、次回起動時にも読み込む
（Git／ソーススナップショットの対象外。リポジトリには `ignorepacket.example.json` のみ）。
ファイルが無いときは Python 側が空の既定プリセットを生成する（既存ファイルは上書きしない）。
初期状態は全て表示。保存ログを開く別ウィンドウにも、起動時点の保存済み設定を適用する。
別ウィンドウや外部エディタで変更した設定は「表示 → 非表示設定を再読込」で取り込む。
編集中・未保存の設定はウィンドウ間で自動同期しない。再読込に失敗した場合は現在の設定を保持する。

## PacketIDごとの flag

各PacketIDにビット flag を付けられる。

| flag | 意味 |
|---|---|
| `&1` | 観測ログ本文と「観測ログを保存…」のテキストから除外する |
| `&2` | SQLite（`packets.sqlite3`）へ書かない。意味解析・会話復元は継続する |

例: `1`=ログのみ、`2`=保存のみスキップ、`3`=両方。設定ファイルは `version: 2` の
`packet_flags` オブジェクト（キーは16進PacketID、値は整数 flag）。旧 `version: 1` の
`packet_ids` 配列は読込時に flag=`1` として取り込む。保存時は常に version 2 で書き出す。

flag&2 は高頻度な歩行・tick などで DB 書込と履歴肥大を抑える用途向け。解析・コード生成の
入力には残る。メモリ退避時は保存スキップ行を意図的未保存として扱い、DB から再表示はできない。

### 多出力パケットの抑制候補（実ログ調査）

あるセッションの RECV 上位例: `00B0` update_status（967）／`0446` showevent（508）／
`09FF` 待機（277）／`0080` unit_removed（216）／`0141`（186・表示未定義）／歩行 `0087`（167）。

- **0446**: 上記どおり flag 変化時のみログ（実装済み）。DB まで落とすなら flag&2。
- **00B0／00B1／0ACB**: HP/SP 等の `@update_status` は表示抑制済み。Zeny／EXP は残す。
- **0087／007F 等**: 歩行・tick。ログ価値が低い場合は ignorepacket flag&1／&2。
- **0141／01D7／00BE**: 表示未定義のまま多い。必要なら PacketID で非表示／保存スキップ。
- **09FF／09FE／09FD**: 出現・移動の再送。名称付き変化のみ残す既存ロジックあり。

Zeny・EXP・会話本文・アイテム増減は抑制対象にしない。

一覧から追加する場合は「パケット詳細」で行を選択し次のいずれかを使う。

- 「選択PacketIDを観測ログ非表示」（flag&1 のトグル）
- 「選択PacketIDを保存しない」（flag&2 のトグル）
- 表の右クリックメニュー（ログ非表示 / 保存しない / 両方）

「NPC」一覧でも個体を選択して「選択NPCの演出を非表示（個体ID）」を押せる。
押下状態で登録済みを示し、もう一度押すと解除する。変更は直ちに適用して保存する。
選択変更だけでは設定を変更しない。NPC名による除外は独立した設定なので、
個体IDの除外を解除しても非表示が続く場合は「非表示設定」で名前のリストも確認する。

- PacketID: 16進数。`0085:1`、`007E:3`、または裸の `0085`（=`0085:1`）を空白・カンマ・改行で列挙する。
  送受信共通。現クライアントの歩行・ticksendのIDをパケット詳細から確認して指定する。
- MOB一括非表示: 出現情報から発信元をMOBと確認できた攻撃・スキル通知を観測ログ非表示にする。
  攻撃は008A/02E1/08C8、スキルは013E/07FB/01B9/01DE/011A/09CB/0117。
  発信元不明や未対応構造は表示を残す。プレイヤーからMOBへの攻撃は対象外。
  （MOB一括はログ非表示のみ。SQLite保存スキップにはしない。）
- NPC演出リスト: 1行に`id:4631724`、`id:0x46ACAC`、`name:案内人`のいずれかを指定する。
  ActorIDは10進数（0x付きなら16進数）、名前は完全一致。いずれかに一致すれば非表示。
  対象はエモーション00C0、エフェクト019B/01F3、効果音01D3、外見変更01B0、
  対象付きプログレスバー09D1、マップマーカー0144、頭上メッセージ08B3。
  通常の会話ウィンドウの台詞・選択肢は残す。
  02F0のプログレスバーはActorIDがないためNPC指定では除外しない。必要ならPacketIDで除外する。
  BGM通知07FE/0B8CもActorIDがないため、非表示にする場合はPacketIDを指定する。
  カットインにはNPCのActorIDがないため、このリストでは除外しない。
  必要ならPacketID 01B3を指定すると全カットインを非表示にできる。

NPC名とMOB分類は受信時点の出現情報で記録する。ActorIDの再利用によって
過去の分類を変更しない。名前未取得時の演出には名前指定が効かないためActorID指定を使う。
明示したActorIDは出現情報が欠けていても適用するが、MOBやプレイヤーと判明していれば除外対象にしない。
ActorID指定は全マップ・セッションへ適用されるため、必要に応じてリストを整理する。

flag&1 の対象は観測ログ本文と「観測ログを保存…」のテキストのみ。
flag&2 を付けない限り、パケット取得・生ログ・SQLite・パケット詳細一覧・基本データ更新・
NPC/MOB解析・生成コードは保持する。設定を解除すれば、メモリに残る観測ログを再表示できる。
不正な設定ファイルは適用せず、画面の状態表示へエラーを出す。

## 今回の到達点

- GitHub運用（Issue／PRテンプレ、作業合意、offscreen CI）と着手単位の docs 再同期。
- rAthena 生成プロファイル／受信表示 JSON、イベントマーカー 0446、帽子エフェクト 0A3B の観測保持（命令化はコメント止まり）。
- 会話資源・外部演出の明示採用ゲート、手動タイマー採用範囲の拡張（overhead／コメント種別）。
- MOBスキル候補の明示的な文字列 VAL 契約と辞書の版／出典分離方針。
- 状態／視覚効果辞書の任意日本語説明レイヤ（`descriptions`／`description_sources`）。SC変換・集計は不変。
- 0x0ADF 観測ログの setnpcgroup／setnpctitle 形式、本人名・パーティ／ギルド／ActorID の保護置換。
- カート移動 SEND（0x0126／0x0127）を NPC の getitem／delitem 等へ誤帰属しない抑止。
- 接触試行の比較表示（座標・符号付き dx/dy・歩行 SEND／受信／転送 Packet）。半径の自動拡大はしない。
- MOB 配置の amount／delay1／delay2 は観測自動補完対象外（手動編集のみ）と着手単位の現状同期。

個別の仕様は各 docs と PR #1–#32 の該当記録を参照。

## 今回の到達点

- クライアントナビ `08E2`（PACKET_ZC_NAVIGATION_ACTIVE）の構造化観測。会話中は `navigation_action` コメント、会話外は `navigation_active`。`navigateto` 実行命令は未生成（#123／#124）。
- cloak 仮説メモと `appearance_vs_initial`、同セル接触候補 `colocated_touch_npcs`（#124／#125）。OnTouch→cloakoff リスト命令は未実装。
- 観測ログの actor コメントを名称取得時 `名称(actor_id), x, y` へ。ignorepacket に PacketID ごとの flag（&1 ログ非表示、&2 SQLite 保存スキップ）とパケット詳細からの追加 UI（#126）。
- showevent（0446）: NPC `showevent_flag`（既定 -1）。flag/kind 変化時のみログ。`state=9999` は spawn 無しなら観測ログのみの NPC 判定ラベル（#126）。
- update_status（00B0／00B1／0ACB）: HP/SP 等の多発行を観測ログから抑制。Zeny／EXP は残す（#126）。
- 大きな生ログの GUI 再解析上限を設定→記録で変更可能に（#122）。

個別の仕様は各 docs と PR #122–#126 の該当記録を参照。

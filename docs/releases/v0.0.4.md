## この版の範囲

- プロセス・複数接続の受動TCP取得、送受信、HTTP PASS、定義に従う分割と欠落・再送の処理。
- 基本データとNPC/MOBの初回／差分観測、サーバーIP・PORT・ActorID順の一覧と一括出力。
- 配置付き全NPC出力、会話統合、選択肢・反復while、入力応答、close/close2と未応答終了の区別。
- OnTouch、インスタンス名、初回HIDDEN/CLOAKED、group/title・waitingroom・職業外見のOnInit。
- shop/callshopと観測条件を満たす所持品・装備・精錬・姿勢・倉庫・床アイテム命令候補。
- MOB性能／スキル／配置の根拠整理と、手動設定・確認後の編集用候補出力。
- 演出・会話開始・マップ到着の基準点比較と保存・再開。従来の手動採用・時刻入力によるタイマー候補。
- 生ログの単独／複数再解析、作業プロジェクト、外部書式、ignorepacket。

直近の点検で、専用class変更の重複／視界外出力、統合後OnTouch欠落、不正初期classの一括出力停止、
外見履歴の欠落通知、インスタンス間の初期表示状態混同を修正した。
参照イベントスクリプトから未観測の処理・条件・タイマーを補完していない。

## 保存物と再作成

```powershell
python -m tools.build_snapshot --output-dir dist
```

- `dist/KYRiE-v0.0.4-source.zip`: コード、設定、docs、テスト、手順、PacketLength.txt。
- ZIP内`KYRiE-v0.0.4/SNAPSHOT.json`: 同梱ファイルのサイズ・SHA-256一覧。自己ハッシュは含めない。
- ZIP横`KYRiE-v0.0.4-source.zip.sha256`: ZIP全体のSHA-256。

許可したソースフォルダ・拡張子・ルートファイルだけを収集し、ZIPの時刻と順序を固定する。
同じソース内容なら同じZIPになる。既存ZIP／ハッシュは上書きしない。再作成時は別の出力先を指定する。
`requirements-lock.txt`は検証時の環境版の記録で、新規環境への導入は未確認。

除外するもの: logs、生DB、クライアントEXE、抽出定義・レポート、参照リポジトリ、
ルートの生成NPCコード、キャッシュ、既存配布物。`client/README.md`のみ説明として含める。
`config/ignorepacket.json`はZIP内だけ空の既定設定にする。作業側の除外設定と各データは変更しない。
元ログと生成候補も保存したい場合は、ソースZIPとは分けて私有バックアップを作る。

   隔離した検証環境で確認する。観測値と設定値・DB対応は人が確認する。

# v0.0.12 ソーススナップショット

[資料一覧](../README.md) · [README](../../README.md) · [前の版](v0.0.11.md)

作成日 2026-11-23（日本時間）。コードの基点は PR #158 まで反映した `main` の `bf3ab23`。

## 変更点

- NPC の個別出力と一括出力でワープ、ショップ、OnTouch の推定を揃えた。CLI でも OnTouch 推定とタイマーのインデントを反映する（#150–#152）。
- 起動時に選択するプロセスを設定できる。Auriga の観測結果からカメラ・UI の命令候補を追加した（#153、#155）。
- 平文 HTTP の観測を設定から有効にできる。rAthena の既知ルートでフォーム項目名、JSON キー、応答の `Type`、データ件数を確認できる（#156）。
- HTTP リプレイ集計は保存済みの観測結果を使い、テキスト保存はゲーム通信と HTTP の観測順を保つ（#157）。
- 診断用 JSONL と再解析用の生ログを個別に保存できる。ソース ZIP の収録範囲を Git の追跡対象に絞った（#158）。

## 検証と保存物

版の整合、TCP・HTTP 観測、ログ保存、再解析を機能別テストで確認する。
ソース ZIP と SHA-256 を作成し、ZIP 内の `SNAPSHOT.json` で各ファイルのハッシュを検証する。

今回の保存物は private ソース ZIP。生ログ、DB、クライアント EXE、ローカル設定は収録対象外。
起動手順はルート README、HTTP の対応範囲は [取得の診断](../capture/capture-analysis.md) を参照。
